## Why the app needs this
D8: deterministic coach now, own model later — which needs a consented dataset of laps, tips and
human feedback from the start.

## What exists today (verified 2026-11-04)
- `API/Controllers/CoachingController.cs` — `[Route("api/[controller]")]`, `GET sessions/{id}/tips` (PRO), `POST sessions/{id}/chat` (ELITE, stub); heuristic tips; `Forbid("…")` bug at lines 31, 56 (H-11).
- `LapCorners` provides per-corner metrics.

## The change
### Contract
| Method & path | Auth | Request | Response | Errors |
|---|---|---|---|---|
| `GET /api/me/ai-consent` | user | — | `{ granted, version, grantedAt? }` | — |
| `PUT /api/me/ai-consent` | user | `{ granted, version }` | `204` | 400 stale version |
| `GET /api/coaching/laps/{lapId}/tips` | owner | `?reference=pb|leaderboard|challenge` | `[{ tipId, corner, ruleId, text, timeGainMs, params }]` | 403 `upgradeRequired` for leaderboard ref on free |
| `POST /api/coaching/tips/{tipId}/feedback` | owner | `{ vote: 1|-1, comment? }` | `204` (upsert) | 404 |
| `GET /api/admin/ai/export` | admin | `?from&to` | async job → pseudonymised NDJSON of consented laps/tips/feedback | — |

### Data model / migration
`AiConsent`, `CoachTip`, `CoachFeedback` ([07](../07-data-model-and-contracts.md) §1).

### Behaviour
1. Tips generated by the ruleset in [08](../08-ai-roadmap.md) Stage A, persisted with `RulesetVersion`.
2. Export includes only users with consent granted at export time; ids replaced per export.
3. Withdrawal stops inclusion in future exports immediately.

## Compatibility — why the website is unaffected
Old tip route keeps working (delegates to the new engine). Chat stays a stub until Phase 4.

## Security
Export admin-only, audited, stored encrypted, auto-deleted after 30 days.

## Acceptance criteria
- [ ] Each Stage A rule has a fixture lap that triggers it and one that doesn't.
- [ ] Feedback upserts; non-owner → 404.
- [ ] Export excludes non-consenting and withdrawn users.

## Rollout / rollback
Consent screen first (beta), tips/feedback at launch. Rollback = old heuristic.
